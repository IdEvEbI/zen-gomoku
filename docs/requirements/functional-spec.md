## 文档信息

- **项目**：zen-gomoku（禅五子棋）
- **版本**：v0.4（禁手与规则切换）
- **最后更新**：2026-08-05
- **实现对照**：以 `develop` 分支已合入功能为准；算法细节见 [ai-agents.md](../design/ai-agents.md)；禁手见 [forbidden-moves.md](../design/forbidden-moves.md)

## 1. 引言

### 1.1 目的

本文档描述 zen-gomoku 的功能需求，作为开发与验收的依据，并与当前 H5 实现保持同步。

### 1.2 范围

- **产品**：15×15 标准五子棋；支持**人人**与**人机**对战。
- **平台**：PC Web、Mobile H5、微信内置浏览器；交互统一处理 Pointer（Mouse / Touch）。
- **AI**：Phase 1 赢法启发；Phase 2 Minimax + α-β 与四级难度（已实现）；Phase 3 预留 AlphaZero 风格接口。
- **棋谱**：项目自定义 JSON；本地存储保存/加载、文件导入/导出；支持复盘。
- **小程序**：架构预留（逻辑与视图分离），本版本不交付。

### 1.3 定义与缩写

| 术语     | 说明                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| 五子棋   | 横、竖、斜连成五子即胜                                                                  |
| 天元     | 15×15 中心交点 `(7, 7)`（0-based）                                                      |
| 星位     | 棋盘参照点：天元 + 四角 `(3,3)(3,11)(11,3)(11,11)`                                      |
| 人人对战 | 两名人类玩家轮流落子                                                                    |
| 人机对战 | 一名人类与 AI；可选人先或 AI 先（先手执黑）                                             |
| 复盘     | 按 `displayHistoryIndex` 回放，不修改 `history`                                         |
| 规则     | 可选 **自由**（`freestyle-v1`，无禁手）或 **禁手**（`renju-cn-v1`，仅黑三三/四四/长连） |
| 和棋     | 棋盘满且无五连判和（已实现路径）                                                        |

## 2. 功能需求

### 2.1 核心玩法

| 编号      | 功能            | 描述                                                          | 优先级 | 状态   |
| --------- | --------------- | ------------------------------------------------------------- | ------ | ------ |
| F-REQ-001 | 标准棋盘        | 15×15 格线；绘制五星；响应式正方形容器                        | P0     | 已实现 |
| F-REQ-002 | 落子            | 交点落子，黑先白后；**空盘首手必须天元**                      | P0     | 已实现 |
| F-REQ-003 | 胜负判定        | 四向五连；一方胜即结束；禁手下黑恰五胜、长连不记胜            | P0     | 已实现 |
| F-REQ-004 | 重新开始 / 终局 | 终局遮罩；可复盘或重新开始；和棋可选路径                      | P0     | 已实现 |
| F-REQ-016 | 规则切换        | 自由 / 禁手（仅黑三三·四四·长连）；切换清空重开；禁手空点红叉 | P1     | 已实现 |

### 2.2 多端与交互

| 编号      | 功能       | 描述                                            | 优先级 | 状态   |
| --------- | ---------- | ----------------------------------------------- | ------ | ------ |
| F-REQ-005 | PC 落子    | `pointerdown` → 物理坐标 → (row, col)           | P0     | 已实现 |
| F-REQ-006 | 触摸落子   | 与 PC 同一套 pointer 映射；`touch-action: none` | P0     | 已实现 |
| F-REQ-007 | 响应式棋盘 | 正方形 `--board-size` + DPR Canvas，避免拉伸    | P0     | 已实现 |

### 2.3 AI（分阶段）

| 阶段    | 行为                                                        | 状态               |
| ------- | ----------------------------------------------------------- | ------------------ |
| Phase 1 | `HeuristicAgent` / `RandomAgent`（赢法启发）                | 已实现（猪八戒等） |
| Phase 2 | `MinimaxAgent` + α-β；四级：沙和尚 / 猪八戒 / 孙悟空 / 唐僧 | 已实现             |
| Phase 3 | 预留 `AlphaZeroAgent`                                       | 未实现             |

**人机产品规则（已实现）：**

- 可选「你先（执黑）」或「AI 先（执黑）」；切换先后手会清空并重开。
- 可选规则「自由 / 禁手」；切换规则会清空并重开；AI 走法过滤黑方禁手。
- 默认难度：猪八戒；可切换对手等级。
- AI 回合有短延迟与「AI 思考中」提示；不可抢落。

详见 [ai-agents.md](../design/ai-agents.md)。

## 3. 非功能需求

- **性能**：落子 UI 反馈应及时；Phase 2 AI 有单步时限（悟空约 180ms、唐僧约 350ms 搜索窗，另加短 UX 延迟）。
- **兼容**：Chrome / Safari / 微信内置浏览器近期版本。
- **无障碍**：可选；当前以触控/鼠标为主。

---

## 4. 验收标准

- P0 功能在桌面与移动 H5 可完成人人 / 人机完整对局（含天元开局、终局重开）。
- 坐标换算、胜负判定、棋谱解析、AI 堵四/冲四等有单元测试覆盖。
- 非法落子（已有子、非天元首手、非己方/AI 回合、复盘浏览中）提示明确且不改 `history`。
- 人机四级与先后手行为与 [ai-agents.md](../design/ai-agents.md) 一致。
