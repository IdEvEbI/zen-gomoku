## 1. 北极星

做一款**棋力可信、练习体系完整、广告不毁局**的五子棋微信小程序：  
人能爽打、能学、能约战；营收与影响力是副产物。

**路径**：继续 **H5 打磨棋力 / 打谱 / 练习** → 迁小程序（约 3 个月可对外人机+打谱）→  
人人在线与段位（约 6 个月）→ 上线后再训 ONNX，挂「如来佛」。

---

## 2. 产品形态（终态）

| 能力        | 决策                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| 平台        | 终态微信小程序；当前主战场 H5（逻辑层复用）                                                          |
| 账号        | **微信登录 + 手机号**；**不支持游客**                                                                |
| 人人        | 邀请码房间 + 随机匹配；**观战**、**断线重连**；云开发或自建 Node 均可                                |
| 人机        | 沙和尚 / 猪八戒 / 孙悟空 / 唐僧（人设见下）；预留「如来佛」接口                                      |
| 规则        | **默认自由**；设置开禁手；人机四级均支持双规则                                                       |
| 练习 / 教学 | **学堂闯关**（规则·死活 + 完整 26 开局 + 分级 VCF/VCT）；双规则分轨；见 [teaching.md](./teaching.md) |
| 打谱        | 照谱落子 + **每步盘面分析**（依赖唐僧）；见 #73                                                      |
| 段位        | **仅排位局**计分；好友局不计；体感接近**象棋段位**（非纯 Elo 展示）                                  |
| 音频        | BGM（可关）+ 落子等音效                                                                              |
| 广告        | 首版：**可选激励视频**（含教学提示加次）；**插屏默认关**；娱乐优先                                   |

## 3. 人机四级（小程序前重做）

| 角色   | 定位                       | 实现方向（目标态）                                      |
| ------ | -------------------------- | ------------------------------------------------------- |
| 沙和尚 | 入门 / 噪声                | **≈ 现猪八戒**：赢法表 + 启发 + 随机选点                |
| 猪八戒 | 防守流                     | 26 开局书 + αβ + VCT/VCF 阵型；评估偏防守               |
| 孙悟空 | 进攻流                     | 同上骨架；评估偏进攻                                    |
| 唐僧   | 攻守兼备、当前最强         | 同上骨架 + 最深搜索 / 最完整威胁策略                    |
| 如来佛 | **不进首发**；上线后 ML 档 | ONNX（Policy/Value）+ 唐僧级搜索；开发期预留 Agent 接口 |

近期精力：**VCF / VCT 棋力优先**（引擎能力先于产品壳与教学 UI）。

教学与引擎共用内容资产；**教学排在 VCF/VCT 之后**（详见 [teaching.md](./teaching.md)）。

| 里程碑 | 目标窗口（自 2026-08） | 对外交付                                                                      |

## 5. 学术与知识产权（已定 + 门禁）

| 项   | 决策                                                           |
| ---- | -------------------------------------------------------------- |
| 软著 | 推进；主体意向：**数科院**                                     |
| 论文 | 数科院第一单位、刘凡一作；主叙事 **ONNX / 自对弈**；**不赶工** |
| 专利 | 若算法有可权利要求（威胁搜索管线、双规则训练等）则尝试         |
| 评测 | 上线前公开页：唐僧 vs 开源引擎（gobang / Rapfi 等协议对局）    |

### 5.1 门禁（必须先过再挂单位名）

1. 取得数科院对「成果归属 / 第一单位署名」的**书面或可追溯内部批准**  
   （职务发明与学院科研管理口径）。
2. 对外推广默认「个人作品 / 开源项目」，  
   **不使用**传智集团、黑马、校区渠道或学员数据导流。
3. 训练与爬取：**不默认**用单位算力与未授权棋谱商用再分发；  
   内容策略见 [content-sources.md](./content-sources.md)。
4. 广告素材与话术符合未成年人友好与微信小程序广告规范。
