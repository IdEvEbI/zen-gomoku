## 1. 二十六种标准开局

### 1.1 定义（公共知识）

前三手（黑 1 天元、白 2、黑 3）在对称去重后共 **26** 种，  
日系命名「星 / 月」，英文 **D1–D13 / I1–I13**（Direct / Indirect）。

| 直止（Direct）                                                | 斜止（Indirect）                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------------------- |
| 寒星 D1、溪月 D2、疏星 D3、花月 D4、残月 D5、雨月 D6、金星 D7 | 长星 I1、峡月 I2、恒星 I3、水月 I4、流星 I5、云月 I6              |
| 松月 D8、丘月 D9、新月 D10、瑞星 D11、山月 D12、游星 D13      | 浦月 I7、岚月 I8、银月 I9、明星 I10、斜月 I11、名月 I12、彗星 I13 |

口诀（便于产品内索引，非著作权主张）：  
「寒星溪月疏星首，花残二月并白莲…」等常见教材口诀可作**自编索引助记**，  
正文讲解需原创。

### 1.2 推荐参考（学习用，非直接搬运）

| 来源                 | URL / 说明                                      | 可用方式                           |
| -------------------- | ----------------------------------------------- | ---------------------------------- |
| 台湾连珠资料「開局」 | <https://587.renju.org.tw/open.htm>             | 核对 26 名与相对坐标；自写中文讲解 |
| 棋谱控开局专题       | <http://g.onegreen.net/wzq/>（花月/浦月等专题） | 学习变化；**勿整站爬讲解商用**     |
| 本仓已有开局种子     | 唐僧互打 / 花月浦月扰动（见 alphazero-lite R1） | 程序生成主谱与分支                 |

### 1.3 落地建议（本产品）

1. **数据层**：JSON 固化 26 开局的前三手坐标 + 对称规范 + 若干「推荐续着」树  
   （自研或老师互打导出）；**闯关关卡**与开局书共用同一数据。
2. **文案层**：关卡内以**一步一句要点**为主（见 [teaching.md](./teaching.md)）；  
   可选每局短述（意图/陷阱）；禁手轨标注合法着差异。
3. **合规**：不批量抓取 onegreen / 商业题库正文；  
   引用公开对局结果时注明赛事与选手（若用）。

## 2. VCT / VCF 练习与「黑石」

### 2.1 术语

| 缩写    | 含义（产品文案可用）                                    |
| ------- | ------------------------------------------------------- |
| **VCF** | Victory by Continuous Four：连续冲四逼杀                |
| **VCT** | Victory by Continuous Threats：连续威胁（含活三等）取胜 |

### 2.2 「Blackstone / 黑石」指什么

用户印象中的 **黑石（Blackstone / 后称 Goro）** 多为 1990s–2000s  
俄罗斯连珠强软（Victor Barykin 一系），用于对弈与局面研究，  
**不是** GitHub 上同名 Java 管理器的练习题库产品。

- 历史简介参考：  
  <http://chiuinan.github.io/game/game/intro/eng/e41/bs37.htm>
- 启示：强引擎 + 可变思考时间；本产品应用  
  **自研 VCF/VCT 求解器出题与验题**，而非依赖闭源黑石二进制。

另：开源 Java 项目 [haslam22/blackstone](https://github.com/haslam22/blackstone)  
是 Gomocup 协议对弈管理器，作者自述 **无 VCT**，可作协议联调参考，不作题库源。

### 2.3 公开题库站点（学习 / 对照难度，勿整站搬运）

| 站点                                          | 说明                       |
| --------------------------------------------- | -------------------------- |
| <https://wuziqi123.com/qipu/vct/> 等          | VCT 追诘、初级～超级题分类 |
| <http://g.onegreen.net/wzq/> List「五子题库」 | VCT 等栏目索引             |

### 2.4 落地建议（本产品）

| 阶段         | 做法                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| **引擎先**   | 唐僧侧先可靠 VCF，再扩展 VCT；求解器对种子局面搜「存在杀」生成题                                           |
| **题包格式** | JSON：`board`、`sideToMove`、`rules`、`solutionMoves`、`difficulty`、`tags`；可选 `stepTips` / `hintCells` |
| **验题**     | CI：每题求解器必须复现唯一或合法解集（教学闯关同一套）                                                     |
| **内容增长** | 人工精选 50 题冷启动 → 求解器批量生成 → 人工抽检                                                           |
| **版权**     | 不爬商业题图/答案入库；难度曲线可对照公开站，题目自造                                                      |

**对照导入**：`npm run import:wuziqi123`（说明见  
[puzzle-import.md](../development/puzzle-import.md)）；精选棋谱归档  
[`fixtures/records/`](../../fixtures/records/README.md)。引擎规格见 [vcf.md](./vcf.md)。

学堂交互（落子才过、提示限次、激励视频）见 [teaching.md](./teaching.md)；  
载体 Issue [#74](https://github.com/IdEvEbI/zen-gomoku/issues/74)。

## 3. 与爬虫的边界

| 允许                                  | 禁止（默认）                          |
| ------------------------------------- | ------------------------------------- |
| 抓取**自有**或明确开源协议的 SGF/JSON | 对题库站 / 讲解站批量爬正文与答案商用 |
| 用引擎生成局面与解答                  | 破解或内嵌闭源黑石题库资源            |
| 手工整理公共开局坐标表                | 未授权转载整本棋书 PDF                |

若未来需引入第三方题包，单独走**授权或合作**议题，不进默认 backlog。
