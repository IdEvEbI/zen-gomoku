## 2. 相对本仓 SWOT（压缩）

|       | 说明                                                                                |
| ----- | ----------------------------------------------------------------------------------- |
| **S** | 产品完整（四级、双规则、开局书、悔棋、SDD）；威胁模块 + rootPolicy 已落地；双仓分工 |
| **W** | 短威胁 DFS ≠ 完整 VCT；无置换表；长程成型弱；四级棋风尚未按「守/攻/均衡」分化       |
| **O** | 完整 VCF/VCT + 26 书可拉开梯度；Worker/WASM；公开 vs Rapfi/gobang 评测建立信誉      |
| **T** | 把「最强」等同于 Rapfi/Yixin 会路线摇摆；只加深 depth 不改威胁能力收益差            |

**一句话**：近期用 **VCF/VCT + 开局书 + 风格化评估** 把唐僧做成 H5 可信最强，  
并拉开猪/悟；ONNX 如来佛放上线后。

## 3. 「最强」分层（与产品对齐）

| 层      | 名称              | 成功标准                                    | 主战场           |
| ------- | ----------------- | ------------------------------------------- | ---------------- |
| **P0**  | H5 可信唐僧       | 完整 VCF + 可用 VCT；认真下很难赢浏览器唐僧 | 本仓古典增强     |
| **P0b** | 四级棋风          | 沙=噪声入门；猪偏守；悟偏攻；唐均衡最强     | 本仓（小程序前） |
| **P1**  | 可进化老师        | Policy + Value + 自对弈                     | zen-gomoku-ml    |
| **P2**  | 如来佛 / 引擎上限 | ONNX + 唐僧搜索；或 WASM/C++ 协议引擎       | 上线后           |

产品命名：**西游四级**服务梯度；**如来佛**为第五档接口预留，不进首发。

## 4. 四级人设（目标实现）

| 角色   | 棋风     | 算法骨架                                       | 相对强度 |
| ------ | -------- | ---------------------------------------------- | -------- |
| 沙和尚 | 入门噪声 | **现猪八戒水准**：赢法表 + 启发 + 随机 / Top-K | ★        |
| 猪八戒 | 防守流   | 26 开局 + αβ + VCF/VCT；评估与选点偏堵偏守     | ★★       |
| 孙悟空 | 进攻流   | 同上骨架；评估与选点偏杀偏攻                   | ★★★      |
| 唐僧   | 攻守兼备 | 同上 + 更深 / 更全威胁与 root 纪律             | ★★★★     |
| 如来佛 | ML 档    | `IAgent` 预留；ONNX + 搜索（M5）               | ★★★★★    |

### 4.1 实现约束

- 猪 / 悟 / 唐共享搜索与威胁模块，差异主要在  
  **depth / 时间 / 评估权重 / 开局书使用策略**。
- 沙和尚**降级**为启发式噪声档，避免与猪同构。
- 自由 / 禁手双规则四级均支持（产品决策）。

## 5. 排期原则（近期精力：VCF/VCT 优先）

1. **立即**：在现有 `threats` / `rootPolicy` 上扩展 **完整 VCF**，再扩展 **VCT**；  
   单测 + 对局回归。
2. **并行轻量**：`IAgent` / 难度表预留 `rulai`（如来）占位，无模型时不可选手或灰显。
3. **人设重做**：沙降级 → 猪/悟风格权重 → 唐吃满威胁能力（小程序前完成）。
4. **开局书**：26 种标准开局接入猪/悟/唐（数据见 [content-sources.md](./content-sources.md)）。
5. **公开评测**：唐僧 vs gobang / Rapfi（或 Gomocup 协议）写入公开页（M1）。
6. **老师数据**：威胁+VCF 版唐僧稳定后再大批量导出，供 ml 仓。
7. **ML / 如来 / 论文**：产品高一段落后；论文叙事偏 ONNX/自对弈，不挡 M1–M3。
