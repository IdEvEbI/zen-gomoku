# 音频素材说明

| 文件                       | 用途                                | 许可         |
| -------------------------- | ----------------------------------- | ------------ |
| `place-stone-original.ogg` | 落子（当前默认，playbackRate 1.75） | **CC0**      |
| `place-stone.wav`          | 提亮缩短试验版（备用）              | **CC0** 衍生 |

## 来源

- 原 WAV：Freesound [put_item.wav](https://freesound.org/people/j1987/sounds/335751/) by j1987（CC0）
- OGG 收录：[appgurueu/go](https://github.com/appgurueu/go) `go_board_place.ogg`
- 当前策略：播原版 OGG，`playbackRate = 1.75`

## 常见落子音效类型（调研）

| 类型           | 听感             | 代表来源                                                                                    |
| -------------- | ---------------- | ------------------------------------------------------------------------------------------- |
| 木盘闷响       | 厚、低频多、偏长 | 当前原版 put_item / 部分实录音                                                              |
| **短促「嗒」** | 清脆、50–150ms   | 多数五子棋/H5（爱给网等素材库主推）                                                         |
| 云子磕盘       | 硬脆、多样本随机 | [Online-Go](https://github.com/online-go/online-go.com) stone packs                         |
| 木棍短 click   | 极短、偏 UI      | Freesound [Wooden Short Click](https://freesound.org/people/Robo9418/sounds/840321/)（CC0） |
| 石碰石         | 高频 click       | Freesound stone click 类                                                                    |

行业习惯：**短、亮、可连点**，避免 0.5s+ 低频拖尾。

若仍不满意，可再换 Wooden Short Click（CC0）或合成「嗒」声。
