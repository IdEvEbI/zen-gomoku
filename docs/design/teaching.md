## 1. 目标与边界

| 做                                    | 不做（本阶段）                    |
| ------------------------------------- | --------------------------------- |
| 新手可闯关学会规则、26 开局、分级杀棋 | 长图文为主的「读书」课            |
| 内容资产同时喂教学与唐僧开局书/验题   | 用教学 UI「替代」VCF/VCT 引擎开发 |
| 提示次数可激励视频补充（娱乐优先）    | 默认插屏打断闯关                  |

**与唐僧棋力**：教学本身不抬引擎；**VCF/VCT 求解器 + 开局数据**抬唐僧，教学复用同一资产。  
故排期：**VCF → VCT → 题包/闯关教学 → 打谱分析（#73）**。

## 3. 交互形态：关卡闯关

1. **落子才过**：局面给定，玩家落在正解（或合法解集）才进入下一步/通关。
2. **步后一句要点**：每步成功后展示短提示（意图/形/为何这手），不替代动手。
3. **提示（Hint）**：过不了可点提示；**每日免费次数有限**；用尽后可看**激励视频**加次数。
4. **广告边界**：提示加次用激励视频；闯关过程中**不开默认插屏**。

题包格式沿用 content-sources（`board`、`sideToMove`、`rules`、`solutionMoves`、`difficulty`、`tags`、  
可选 `stepTips[]` / `hintCells`）。
