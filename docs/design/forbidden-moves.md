# 中国规则禁手规格（实现对照）

- **规则 ID**：`renju-cn-v1`（见 `src/core/rules.ts`）
- **算法**：`src/core/forbiddenMoves.ts`
- **对应 Issue**：[#54](https://github.com/IdEvEbI/zen-gomoku/issues/54)

## 适用范围

- **仅黑方**受禁；白方无三三 / 四四 / 长连限制。
- **成五优先**：黑方落下后形成恰五连，则该手合法且黑胜，即使同形可能构成四四。

## 禁手类型

| 类型 | 含义                                  | 产品提示     |
| ---- | ------------------------------------- | ------------ |
| 长连 | 同一直线连续 ≥6 子                    | 黑方长连禁手 |
| 三三 | 一子同时形成两个及以上活三            | 黑方三三禁手 |
| 四四 | 一子同时形成两个及以上四（冲四/活四） | 黑方四四禁手 |

活三 / 四 的判定要点：

- **活四**：该轴两端空点落下均可成五（连续四子两端开口）。
- **冲四**：仅一端可成五 —— **不是**活四。
- **活三**：存在空点落下后形成活四（眠三延伸成冲四不算）。
- **四三合法**：已成「四」的方向不计入三三。

## 与自由规则

`freestyle-v1`：无禁手；≥5 连（含长连）即胜。

## UI 标记

禁手模式下，空点若黑方落子为禁手，棋盘上以**半透明红叉**标出（常见还有红圈；本项目用叉以区别于最近落子的红圈）。白方回合亦显示，便于捉禁教学。
