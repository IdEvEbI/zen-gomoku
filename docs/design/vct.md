## 1. 定义与边界

| 概念      | 本仓含义                                  |
| --------- | ----------------------------------------- |
| **VCF**   | 连续冲四；VCT 的真子集                    |
| **VCT**   | 连续威胁：冲四 + 活三 + 叉，直至双杀/成五 |
| **与 αβ** | 根上战术探针；失败则降级软挡 / αβ         |

禁手：形检测与合法着依赖现有规则钩子；MVP 以 freestyle 回归为主。

## 2. 搜索结构

```txt
attackNode（OR）
  ├─ 若有冲四/胜点 → 先 vcfExists（短路）
  ├─ 候选：叉/冲四/活三（排序截断）
  └─ 试着 → defendNode

defendNode（AND）
  ├─ 守方一步胜 → 失败
  ├─ 攻方胜点≥2 或 可成活四点≥2 → 胜（双威胁）
  ├─ 挡点 = 胜点 → 可成活四点 → 冲四点（窄于 listForcedReplies）
  ├─ 挡点过多 → 未证（失败，不误报胜）
  └─ 每个挡点后攻方仍 VCT → 胜
```

### 2.1 根策略顺序（唐僧 · #81）

1. 一步胜 / 硬必防 / 己方活四 / 双胜点快路径
2. **己方 VCF**
3. **对方活四端**（`measureThreatResidual` 择优）→ **对方 VCF 必防**
4. 叉对杀抢攻（仅当对方无待破 VCF）
5. 对方叉：**统一强迫着**（冲四候选；`inspectForcingOutcome` 看应手后谁还有杀，优先保留己方 VCT）→ 否则软搜
6. **己方 VCT** → **对方 VCT 必防**
7. 其余软威胁 → αβ

相对 #70：活四端 / VCF 必防先于叉对杀；有叉时禁止「冲第一个四」假抢先（对局 2026-08-10-01-53-06：`f9` 优于 `e10`）。

### 2.2 参数（唐僧）

| 参数                        | 值                                                     |
| --------------------------- | ------------------------------------------------------ |
| `vcfMaxPly` / `vcfBudgetMs` | 12 / 300                                               |
| `vctMaxPly` / `vctBudgetMs` | 12 / 400                                               |
| 战术时限                    | 自 `getNextMove` 起 VCF 窗 + VCT 窗，且不超过总 1000ms |
